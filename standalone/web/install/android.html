Instalar en Android

App a pantalla completa, sin Play Store y sin Home Assistant.

Abrir HADomotics
  1. Abre este enlace con Chrome (no el visor de GitHub).
  2. Menú ⋮ → Instalar aplicación / Añadir a pantalla de inicio.
  3. Confirma. Aparecerá el icono como una app nativa.

Si Chrome no muestra “Instalar”, usa Añadir a pantalla de inicio.

El servidor del piloto debe estar en tu red (PC o NAS). Ejemplo: http://192.168.1.181:8099
