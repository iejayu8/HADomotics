Instalar en iPhone / iPad

Apple no permite instalar un IPA desde GitHub sin App Store / TestFlight. La vía oficial y estable es una app web instalable (PWA) desde Safari.

Abrir HADomotics en Safari
  1. Abre este enlace con Safari (no Chrome ni la app de GitHub).
  2. Pulsa el botón Compartir (cuadrado con flecha).
  3. Añadir a pantalla de inicio → Añadir.
  4. Ábrela desde el icono; se abre a pantalla completa.

Servidor del piloto en tu red, por ejemplo http://192.168.1.181:8099
